# Systre / Gavrog

`mofid_wrapper` bundles `Systre-experimental-20.8.0.jar`, taken as-is from the
upstream [`mofid`](https://github.com/snurr-group/mofid) repository's
`Resources/` directory, where it is used unmodified to determine MOF
topology via the Systre command-line tool from the
[Gavrog](https://github.com/odf/gavrog) project (O. Delgado-Friedrichs).

No LICENSE/NOTICE file for this jar was found bundled in the upstream mofid
repository at the time `mofid_wrapper` was packaged. Before publishing a
release that bundles this jar, confirm redistribution terms against the
upstream Gavrog project's own license.
